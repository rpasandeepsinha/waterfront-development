# Subscription states

For the subscription model, we have two different state fields: `administrative_status`, and `technical_status`.

## The difference
- `administrative_status`
    - For administrative purposes, like insight and financing.
- `technical_status`
    - For technical purposes, like conveying the active state from a third party to the customer support agent or developer.

For more info on what possible values the `administrative_status` field may have, [click here](administrativeStatus.md).

For more info on what possible values the `technical_status` field may have, [click here](technicalStatus.md).
