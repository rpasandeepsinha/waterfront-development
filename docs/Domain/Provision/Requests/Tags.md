# Tags

All request can have tags. A request can have a single tag, but can also have multiple requests.

The subscription uuid will always be assigned to each request, but more tags can be added as well.

Tags can be used to later retrieve a collection of requests based on a certain tag. This way you
can retrieve requests based on a certain subscription. But if customer uuid would also be assigned
as a tag, then you can request all request based on a certain customer.
