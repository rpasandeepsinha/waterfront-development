# CreateSitebuilderRequest

Most params should be clear what they should contain, but here is some extra explanation about some.

## Packages

This is an array of integers containing the package ID's created in basekit. This should contain all packages which need to be provisioned.

Creating these packages in Basekit can't be done by us, for this we would need to contact our account manager at basekit. We can find the possible packages added to our account in the GUI of Basekit.

## Contract period

Only a single contract period can be set for all packages. It's not possible to have a different contract period for one of the packages.
